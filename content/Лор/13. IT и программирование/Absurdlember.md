Absurdlember - довольно простой язык программирования. Он отличается довольно легким синтаксисом. Им можно открывать, проверять, настраивать и перемодулировать файлы и файловые объекты. Очень ценится офисными работниками, ведь он облегчает им работу.
Текстовые редакторы Absurdlember: Absurdos, Didos, Durkois, Welent. 
**Доступная версия: 1.0**

Сейчас мы откроем с вами файл по имени бебра.
```
[OPEN.file.bebra.png]
```
Важно после file. внести название файла, а потом его тип. 

После того, как вы откроете файл, вы сможете начать работу с ним.
```
[FORopen.check.file] 
```

Absurdlember просканирует/проверит файл и выдадит соответствующую информацию
```
[NAME:bebra
1 MB
Type:png(open)] 
```

Тип работы.
Тип работы может быть на всю программу, либо только на её часть. Например:
```
[START.WORK] 

[TYPE:FILE] 

[OPEN.file.bebra.png] 

[FORopen.check.file]
```
//тут мы должны дальше написать просто { и }, чтобы язык не запутался  

```
{ 
         }
[TYPE:FILE.OBJECT]
[OPEN.FILE.OBJECT TO:] 

[bebra.png] 

[FORopen.check.fileobject:]

[FORopen.check.fileobject.bebrick]
```
