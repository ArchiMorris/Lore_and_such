#### Абсурдистанская Сеть Терминалов = АСТ.
АСТ — Язык взаимодействия с файлами. **Версия 1.0**

**Команды:**
```
{  />открыть: арг1: 
>> имя: арг2  }

{  />инфо: арг1: 
>> имя: арг2  }

{  />удалить: арг1: 
>> имя: арг2  }

{  />создать: арг1: 
>> имя: арг2  }

{  />переместить: арг1: 
>> имя: арг2
>>>> в арг3: арг4  }

{  />просмотр: арг1:
>> имя: арг2  }

{  />переименовать: арг1:
>> имя: арг2: арг3  }

арг1 — Аргумент 1
арг2 — Аргумент 2
И т.д.
```

**Примеры:**
```
#Открытие файла
{  />открыть: файл: 
>>имя: фото.png  }
АСТ> Файл «фото.png» открыт 

#Информация о файле
{  />инфо: файл: 
>> имя: фото.png  }
АСТ> Информация о файле «фото.png»:
>> Размер: 1 МБ
>> Тип: png 

#Информация о терминале
{  />инфо: терминал: 
>> имя: super_max666  }
АСТ> Информация о терминале «super_max666»:
>> Время работы: 10 мин
>> Всего директорий: 0
>> Всего файлов: 1 
>>>> фото.png
>> Открытая директория: _
>> Открытые файлы: фото.png
>> Ошибки: 0 

#Удаление файла
{  />удалить: файл: 
>> имя: фото.png  }
АСТ> Файл «фото.png» удалён из терминала
{  />открыть: файл: 
>> имя: фото.png  }
АСТ> Файл «фото.png» отсутствует 

#Создание "окна" терминала
{  />создать: терминал: 
>> имя: тест  }
АСТ> Создан терминал с именем «тест» 

#Создание директории
{  />создать: директория:
>> имя: каталог_товаров  }
АСТ> Создана директория «каталог_товаров» 
```

```
#Допустим, у нас есть файл пиво.mp4 и мы хотим поместить его в директорию "каталог товаров". Тогда:
{  />открыть: файл: 
>> имя: пиво.mp4  }
АСТ> Файл «пиво.mp4» открыт
{  />переместить: файл: 
>> имя: пиво.mp4
>>>> в директория: каталог_товаров  }
АСТ> Файл «пиво.mp4» перемещен в директорию «каталог_товаров»
{  />инфо: директория: 
>> имя: каталог_товаров  }
АСТ> Информация о директории «каталог_товаров»:
>> Всего файлов: 1
>>>> пиво.mp4 

#Создание и редактирование txt-файла
{  />создать: файл
>> имя: бебрик
>> тип: .txt  }
АСТ> Создан файл с именем «бебрик.txt»
{  />открыть: файл
>> имя: бебрик.txt  }
АСТ> Файл «бебрик.txt» открыт
Юзер> _ Тут тексттт
{  />открыть: файл
>> имя: бебрик.txt  }
АСТ> Файл «бебрик.txt» открыт
>> Тут тексттт 

#Просмотр файлов в терминалах
{  />просмотр: файлы терминала:
>> имя: test_02  }
АСТ> Список файлов в терминале «test_02»:
>> [1] hello.png
>> [2] донос.pdf
>> [3] инструкция.txt
#Попробуем открыть один из файлов, но используя "быстрый ввод" по номеру
{  />открыть: файл:
>> номер: 2  }
АСТ> Файл «донос.pdf» открыт 

#Просмотр файлов в директориях
{  />просмотр: файлы директории:
>> имя: boobs  }
АСТ> Список файлов в директории «boobs»:
>> [1] 666.avi
>> [2] горловое_пение_шаманов.mp4
>> [3] секрет.exe
>> [4] nsfw.png
```
