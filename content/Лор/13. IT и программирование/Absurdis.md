#### Версия: 1.0

Синтаксис и начальные операции в языке Absurdis довольно просты. В начале вы должны написать следующее:
```
{ function move.in
function move.at 
                  }
```
Это база баз, без этих функций в начале вы не сможете написать код. 

Чтобы выводить текст, нужно писать:
```
write.RightLine("текст")
Чтобы выводить информацию для вывода(итога), нужно писать
Write.RightLine:(пишите, что вам нужно) 
```

##### Переменные.
Переменные хранят различную информацию. Например, количество патронов в автомате в игре.
Возьмем это за пример. 
```
Int патроны(мы можем писать названия переменных на всех языках) = "сумма" 
```

Переменные переменных
Переменные могут перенаправляться на друг друга, например.
```
Int патроны = 42
Int автомат = int патроны. 
```

Действия с переменными.
Давайте напишем нашу первую программу.
```
{{ function move.in
function move.at 
}} 

{{ Int патроны = 42
Int автомат = int патроны
}}                                           

{{ Write.RightLine:
int автомат
}}
```

```
ИТОГ:
Int автомат = int патроны
Int патроны = 42
Тотальный итог:42
```

##### Условные операторы.
Можно вспомнить про операторы esle и if. Оператор if может вам помочь и определить, истинно или не истинно операция. Оператор esle выполняет определённые команды, если операция не истинна.
```
{{function move.in
          function move.at}} 

{{int патроны = 41
         int автомат = int патроны
        if (condition) int автомат = 42:
        to Write.RightLine("Good ammo")
        

       else(condition) int автомат = 41:
       to Write.RightLine("Bad ammo")}}
```

```
ИТОГ:
Working.esle.condition...
Тотальный итог:Bad ammo.
```
